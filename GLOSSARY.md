# LeanEiffel

LeanEiffel is an Eiffel-derived programming language and integrated toolchain intended for use by AI coding agents, built on the existing Gobo Eiffel compiler and Lean 4 verifier.

## Language

**Hybrid verification**:
LeanEiffel's contract policy: runtime checks are retained, supported contracts can be proved with Lean, and contracts that remain unproved are explicitly reported.
